# v0.2 Release Candidate

本目录保存 v0.2 可读发布的 RC 证据与书稿资产：

- `readiness.json` / `readiness.md`：门禁报告
- `release-notes.md`：Release Notes 候选
- `aidlc-book-v0.2.pdf`：书稿 PDF
- `aidlc-book-v0.2-book.html`：书稿 HTML

Pages HTML zip 与最终 `release-manifest.json` 由 `scripts/prepare_release.py` / `release.yml` 在候选目录生成，不在此目录重复存放大体积 zip。
