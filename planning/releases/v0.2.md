## 发布命令（审计轨迹）

```text
scripts/build_book.sh .artifacts/book all
python3 scripts/check_release_readiness.py \
  --policy planning/releases/v0.2-policy.json \
  --json-report releases/v0.2-rc/readiness.json \
  --markdown-report releases/v0.2-rc/readiness.md
python3 scripts/render_release_notes.py --require-ready \
  --readiness releases/v0.2-rc/readiness.json \
  --output releases/v0.2-rc/release-notes.md
python3 scripts/prepare_release.py v0.2 \
  --readiness releases/v0.2-rc/readiness.json \
  --release-notes releases/v0.2-rc/release-notes.md \
  --pdf releases/v0.2-rc/aidlc-book-v0.2.pdf \
  --book-html releases/v0.2-rc/aidlc-book-v0.2-book.html
git tag v0.2
git push origin v0.2
```

`release.yml` 在 tag push 后重建候选并以 draft Release 上传资产；维护者审阅后公开 Release，才会触发 `post-release.yml` 写入正式回执。
