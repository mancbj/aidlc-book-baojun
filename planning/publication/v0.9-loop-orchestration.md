## 风险与并行策略

| 风险 | 缓解 |
| --- | --- |
| 英中漂移 | 每章 Metadata `Chapter ID` 与 `book/chapters/` 文件名一一对应；CI 路径合同 |
| Loop 体量 | 严格按 patch 拆 PR；单 PR 不超过「一章 + 构建」或「一站点多脚本」 |
| Carbon 体积 | 仅 token + 阅读器 CSS/JS，不引入 React 运行时 |
| Release 与 Pages 双轨 | L6 强制 manifest hash 门禁 |
