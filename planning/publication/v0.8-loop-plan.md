# v0.8 ALREADY & KEEP-EXT Loop

目标：在 SHIP 18/18 基线上，把两个 ALREADY 实验升到 verified，并用冻结复现包推进两个 KEEP-EXT；诚实处理 Reader 反馈。

## 已确认范围

### 目标实验

1. `EXP-07-01` · 仓库确定性门禁组合器（ALREADY → verified）
2. `EXP-08-01` · 发布候选来源清单校验器（ALREADY → verified）
3. `EXP-04-03` · 官方 Memory Bank 结构复现（KEEP-EXT → verified，冻结 pin）
4. `EXP-05-03` · 官方 Bolt 类型检查点复现（KEEP-EXT → verified，冻结 pin）

### 治理规则

- 不把 ALREADY / KEEP-EXT 改写成 SHIP
- ALREADY/KEEP-EXT 一旦 `verified`，必须提供可执行合同测试路径，并由 CI 执行
- KEEP-EXT 只验证冻结 pin / 本地复现夹具，不在 CI 抓取外部网站
- Reader：无真实回复则 deferred + known-gap
