# v0.3 Publication Quality Loop

目标：在不破坏十章事实边界的前提下，把可读书稿提升到可发布的出版质量，并以 `v0.3` 正式发布。

## 原则

1. 每轮只改一个目标；改完立即构建、审计、评分。
2. 评分后决策：`KEEP` 提交，或 `REVERT` 回退该轮改动。
3. 源稿保留写作元信息；**只有 release profile 构建**才剥离内部 meta。
4. 不把 `planned` 写成已验证；保留 `𝓔 = Engineering with Exsecutio`。
5. 不提交 `.artifacts/`；不 force push；不自动合并 PR。

## 评分

| 维度 | 满分 | 说明 |
|------|------|------|
| Content | 50 | 正确性、边界、术语、信息卫生 |
| HTML | 25 | 排版、层次、可读性、无障碍 |
| PDF | 25 | 字体、分页、图表、专业版式 |
| **总分** | **100** | 发布阈值：**≥ 92**，且硬门禁全过 |

## 硬门禁

- `python3 scripts/ci_check.py` 通过
- 内部链接 `errors=0`
- release HTML/PDF **无** Metadata / Writing Sprint Card / Draft Completeness / Status Source / Gate checklist / Review Notes / Dxx 验收清单泄漏
- PDF 无缺字；字体嵌入
- 核心术语：`Exsecutio` 不被改成 `Execution`
- 封面、十章、核心公式均在可读产物中

## 轮次计划

| Round | 目标 | 决策点 |
|------|------|--------|
| 00 | 基线构建、评分卡、冻结清单 | KEEP 文档 |
| 01 | Release 信息卫生（`release-profile.lua`） | 泄漏=0 才 KEEP |
| 02 | 结构噪音清理（目录/宣言中的生产元段落） | KEEP/REVERT |
| 03 | 证据边界与 planned 表述 | KEEP/REVERT |
| 04 | 相邻章节边界复核 | KEEP/REVERT |
| 05 | 术语与公式一致性 | KEEP/REVERT |
| 06 | HTML 设计系统（字体/色板/层次） | KEEP/REVERT |
| 07 | HTML 无障碍与目录体验 | KEEP/REVERT |
| 08 | PDF 版式与页边距 | KEEP/REVERT |
| 09 | PDF 分页与孤行控制 | KEEP/REVERT |
| 10 | 图表与 ASCII 框图统一 | KEEP/REVERT |
| 11 | 全书一致性扫尾 | KEEP/REVERT |
| 12 | 对抗审校（泄漏/边界/缺字） | 不过则回修 |
| 13 | 冻结 + `v0.3` 发布 | 总分≥92 |

时间不够时：跳过非阻塞美化轮，优先保证 Round 01 + 硬门禁 + Round 13 发布。

