# v0.4 Evidence & Visual Loop

目标：在 v0.3 出版质量基线上，新增四个可复现实验、九张章节独立 SVG，并诚实处理 Reader 反馈。

## 已确认范围

### 新增 verified SHIP

1. `EXP-03-02` · Unit 与 Bolt 依赖 DAG 校验器
2. `EXP-06-01` · Plan–Walkthrough 偏差审计器
3. `EXP-02-01` · 不可委托判断清单生成器
4. `EXP-04-02` · Standards 漂移检测器

不在 v0.4 中尝试一次实现全部 planned 实验。

### 章节 SVG

- CH-01 继续复用 `fig0-1.svg`
- CH-02～CH-10 各交付一张独立、可编辑、可审计 SVG

### Reader 反馈

- 只处理真实收到的反馈，不生成合成“读者结论”
- 没有新回复时，完成重评并继续公开保留 `READER-RESPONSES`
- known-gap 不阻断 v0.4，但虚假 `responded` 必须阻断

## 每轮协议

```text

→ KEEP 或 REVERT
→ 独立提交
```
