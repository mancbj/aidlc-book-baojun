# v0.8.004 PDF Cover Fix Loop

目标：修复 PDF 封面底部白带，以及公式等号后文字偏小、未垂直居中的问题。

## 交付

1. 3:4 封面按 A4 高度铺满、水平居中裁切
2. 通过 shipout 左下角绝对定位消除页面底部空白
3. `𝓔（人的判断 + AI 能力）` 与左侧主公式同级字号、共同视觉中线
4. PDF 栅格检查、CI、content audit、readiness 与 Release 回执

## 硬门禁

- 第一页底部近白像素比率为 0
- 公式不越界，等号后正文与主公式同级
- `𝓔 = Engineering with Exsecutio` 术语不变
- CI / content audit / readiness 通过
- 不覆盖已发布 v0.8.003 资产，递增到 v0.8.004
