# v0.4 Freeze List

## 术语与章节边界

- 必须保留：`𝓔 = Engineering with Exsecutio`
- CH-07 Verify 不等于 CH-08 Runtime Verify
- specs.md 是参考实现，不是 AI-DLC 唯一形态

## 实验边界

- `planned`、`in-progress`、`ready` 不得写成 `verified`
- verified 只证明实验合同中声明的确定性指标
- DAG 合法不证明计划最优
- 未声明变更不自动等于错误
- 判断清单不证明覆盖全部不可委托判断
- Standards 漂移检测不证明规则在所有仓库都适用
- ALREADY/ready 的 EXP-07-01、EXP-08-01 不在本轮伪装为新 SHIP

## Reader 边界

- 只有真实回复才能把 Reader 槽位改为 `responded`
- 不提交姓名、邮箱、原始全文、完整 transcript 或其他 PII
- Agent 可以 dry-run 和起草匿名摘要，不可伪造观察或替人做最终取舍
- 若 v0.4 发布前仍少于三位回复，继续记录 `READER-RESPONSES` known-gap

## SVG 边界

- SVG 文本必须可编辑，不转 path
- 禁止 `foreignObject`、script、动画与外部 image
- 图中受保护术语与正文事实必须一致
- 自动审计不能替代 PNG/PDF 人工目检

## 发布边界

- readiness `ready` 可以携带 Reader known-gap
- draft/tag/本地资产不等于正式 published receipt
- `.artifacts/v0.4-loop/` 不入库
