## 各版本 Loop 定义

### v0.9.001 · 英文构建脊柱（主线 A）

**Loop 目标**：仓库能「合法地」构建英文书稿产物，而不声称翻译完成。

| Round | 名称 | 交付 |
| --- | --- | --- |
| 01 | source-layout | `book/en/` 目录、frontmatter.en、toc.en.md、manifest 中 `locale` |
| 02 | build-cli | `build_book.py --locale en`、manifest 字段、单元测试 |
| 03 | ci-contract | CI 校验英文源存在、最小 HTML 构建（dev profile） |
| 04 | release-doc | `v0.9.001-policy.json`、VERSIONING、本规划交叉引用 |

**Scorecard 权重建议**：build 40 / ci 30 / docs 20 / release hygiene 10。

**不做**：整书翻译、英文 PDF Release。

---

### v0.9.002 · 英文 Part 0 + CH01–03

**Loop 目标**：国际读者可理解「为什么 AI-DLC」与 Inception 入口。

| Round | 内容 |
| --- | --- |

**验收**：英文章节无占位 marker；Primary Question 各章唯一。

**验收**：release-profile HTML 半本书 `audit_release_content.py` pass。

### v0.9.005 · Carbon 站点 IA（主线 B）

**Loop 目标**：Pages 信息架构与 Carbon 设计 token 落地，无完整阅读器也可发布骨架。

| Round | 交付 |
| --- | --- |
| 01 | URL 方案、`docs/PAGES-IA.md`、Carbon color/type/spacing token（CSS） |
| 02 | 着陆页：封面 + 公式 + 三阶段图（Carbon Grid） |
| 03 | 与 `site/` 驾驶舱导航关系（分域或统一 Shell） |
| 04 | Pages CI：lint 链接、无 `foreignObject` 违规（与书稿 SVG 标准一致） |

**参考**：`memory-bank/standards/` 中 IBM Carbon 倾向；**不**要求引入 React 运行时（静态优先）。

---

### v0.9.006 · 可视化阅读器 v1

**Loop 目标**：章节 HTML 在 Carbon Shell 内可读，体验显著优于裸 Pandoc 单页。

| 能力 | 说明 |
| --- | --- |
| Side nav | Part / Chapter 树 |
| 正文 | 最大宽度、行高、标题层级（Carbon type scale） |
| 图 | SVG 内联 + 可选 modal 放大 |
| 代码 | Plex Mono、复制按钮（可选） |

**验收**：Lighthouse a11y ≥ 90（本地/CI 快照可选）；键盘可遍历 TOC。

---

### v0.9.007 · 双语与 a11y

**Loop 目标**：英/中 UI 与书稿路径统一；满足 a11y 基线。

- `lang` / `hreflang` / 语言切换（localStorage 或 path prefix）。
- 图表 long description；减少动效 `prefers-reduced-motion`。
- README / README.en 指向 Pages 书站而非仅 md 源文件。

---

### v0.9.008 · 阅读站与 Release 同源

**Loop 目标**：Pages 为默认公共阅读面；Release 为离线/归档面；二者 hash 可追溯。

- `prepare_pages.py` 集成书站构建产物。
- `publish-manifest.json` 扩展：`book_html_sha256`、`locale_assets`。
- Release notes 模板更新：`next_goal` 指向 **v0.9.009+**（维护/图优化/实验可视化等），**非** Reader 反馈。

## 风险与边界

| 风险 | 缓解 |
| --- | --- |
| 翻译与中文漂移 | 英文章节 Metadata 引用 `Chapter ID`；CI 检查章节文件一一对应 |
| Carbon + 静态站体积 | 仅打包用到的 token/组件 CSS；SVG 仍本地优先 |
| Pages 与 Release 双轨维护 | v0.9.008 起强制 manifest 同源；单一 `build_book` 入口 |
| 范围膨胀 | 严格 patch-grain；可视化「高度」分 006/007/008 三刀，不合并进 004 |

## 取消项（明确不做）

- **不** 将「等待 Reader A/B/C 回复」写入 `progress/generated/current` 的下一动作。
- **不** 为反馈缺口伪造 `responded` 计数。
- **不** 在 v0.9 系列用「反馈驱动改稿」替代上述双主线（反馈可进 Issue  backlog，不绑 tag）。
